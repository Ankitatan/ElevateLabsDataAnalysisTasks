# Data Cleaning and Preprocessing

## Overview
This project demonstrates data cleaning and preprocessing using the Customer Personality Analysis dataset from Kaggle.

## Objectives
- Identify and handle missing values.
- Detect and remove duplicate records.
- Standardize column names and categorical values.
- Convert dates and correct data types.
- Identify potential outliers using the IQR method.
- Validate and export the cleaned dataset.

## Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Structure
- `data/` — Original and cleaned datasets
- `data_cleaning.ipynb` — Data cleaning and validation workflow
- `cleaning_summary.md` — Summary of cleaning operations

## How to Run
1. Clone or download this repository.
2. Install the dependencies using `pip install pandas numpy jupyter`.
3. Place the original `marketing_campaign.csv` file inside the `data/` directory.
4. Launch Jupyter Notebook and open `data_cleaning.ipynb`.
5. Run the notebook cells in order.
